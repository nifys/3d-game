# 3D Game

Простая браузерная 3D-игра на Three.js. Игрок перемещается по арене, собирает кристаллы и избегает врагов.

## Запуск

Откройте проект локально через HTTP-сервер:

```bash
python -m http.server 8000
```

Затем откройте в браузере:

```text
http://localhost:8000
```

## Управление

- WASD / стрелки — движение
- Space — прыжок
- R — перезапуск после поражения

## Что есть в игре

- 3D-арена
- Игрок-герой
- Враги, которые преследуют
- Кристаллы для очков
- Система здоровья и сложности
- Подготовка к дальнейшему развёртыванию на сайте
